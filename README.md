# CSSteamWebsite
We are developing a Counter-Strike trading platform with a social frontend and secure database. It provides a safe, centralized space for players to search, trade, and discuss in-game skins. Users can create accounts, list items, message others, and verify trades through a reliable, community-driven system.

Additionally, we plan to add many features that include, admin dashboard, community notes, and other features that will be discussed further on. The dependencies for our solution will just be a stable internet connection and access to any web browser. This work is copyrighted and is coursework for students of Birmingham City University.
